Career Tree is an interactive skill development dashboard designed for developers to track their professional growth. The application uses a stack-based architecture where each technology or profession (like PHP Developer or English) has its own dedicated module containing overview statistics, resume information, structured learning paths with difficulty levels, flashcard systems, knowledge bases, and ready-to-use AI prompts. The interface features a clean sidebar navigation with keyboard shortcuts (Ctrl+1-6) and persistent local storage for tracking progress across sessions.

The project is built with vanilla HTML, CSS, and JavaScript, making it lightweight and easy to extend. Each skill stack is self-contained with separate JavaScript files for different sections, allowing developers to add new stacks without modifying core code. The learning section is organized into Base, Light, Medium, Hard, and Exam levels, while the card system supports both single-card practice and an "all cards" grid view. The prompts section provides categorized pre-built prompts for code review, architecture design, debugging, and other common development tasks, making it a practical tool for continuous learning and interview preparation.
